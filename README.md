# SmartLink Basics — Claude Plugins

Official Claude Cowork and Claude Code plugins from [SmartLink Basics](https://smartlinkbasics.com).

## Available Plugins

| Plugin | Description |
|--------|-------------|
| [smartlink-basics](./smartlink-basics/) | Sales CRM tools with the 6-KPI coaching framework |

## Install

Add this marketplace to Claude:

```
claude plugin marketplace add smartlink-basics/claude-cowork-plugin
```

Then install:

```
claude plugin install smartlink-basics@smartlink-basics
```

## About

SmartLink Basics empowers sales leaders with smart solutions to accelerate performance. These plugins bring our CRM data and coaching methodology directly into Claude.

Learn more at [smartlinkbasics.com](https://smartlinkbasics.com).
